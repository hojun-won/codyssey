# 기획서: 코칭 롤플레이 프롬프트 생성기

> 구성원 특징을 입력하면, AI와 코칭 롤플레이를 할 수 있는 프롬프트를 만들어 주는 HTML 페이지  
> 

- 작성자: 원호준  
- 작성일: 2026-11-07  
- 사용한 AI 서비스 / 모델: Claude (Cowork) / claude-opus-5-5

---

## 1\. 대상 사용자

- 코칭 교육을 듣는 리더(직책자)  
- 이런 때 사용합니다.  
  - 원온원 면담을 준비할 때  
  - 코칭 교육의 실습 시간에  
  - 평가 피드백 면담을 앞두고 있을 때

## 2\. 사용 목적

- 실제 면담 전에 어려운 대화를 미리 한 번 해 본다.  
- 역할을 바꿔 구성원 입장이 되어 보고, 내 질문 방식을 돌아본다.  
- 페이지는 **롤플레이용 프롬프트를 만드는 것까지** 맡습니다. 실제 대화 연습은 사용자가 프롬프트를 복사해 Claude나 Gemini 같은 외부 AI 서비스에 붙여 넣어 진행합니다.

## 3\. 화면 구성과 동작

### 3-1. 화면 구성 (위에서 아래 순서)

| 순서 | 영역 | 내용 |
| :---- | :---- | :---- |
| 1 | 제목 | "코칭 롤플레이 프롬프트 생성기" |
| 2 | 사용 방법 안내 | ① 구성원 정보 입력 → ② 프롬프트 생성·복사 → ③ AI 서비스에 붙여 넣고 연습 |
| 3 | 입력 영역 | 아래 입력 항목 표 참고 |
| 4 | 버튼 영역 | \[예시 채우기\] \[프롬프트 생성\] \[초기화\] |
| 5 | 결과 영역 | 생성된 프롬프트, \[복사\] 버튼, 안내 메시지 |
| 6 | AI 바로가기 | Claude, Gemini 링크 (새 탭에서 열림) |

### 3-2. 입력 항목

| 항목 | 입력 방식 | 필수 여부 | 예시 |
| :---- | :---- | :---- | :---- |
| 구성원 호칭 | 직접 입력 | 선택 | 김OO, 편집A (실명 대신 별칭 권장) |
| ① 면담 상황 | 선택 | 필수(기본값 있음) | 원온원 / 코칭 / 평가 피드백 |
| ② 구성원 직무·연차 | 직접 입력 | **필수** | 편집기획 5년 차 |
| ③ 성향 | 여러 개 선택 | 선택 | 내성적, 방어적, 의욕 저하, 성과 중심, 감정 표현 많음 |
| ④ 현재 이슈·고민 | 직접 입력 | **필수** | 최근 마감 지연이 잦고 팀 회의에서 말수가 줄었다 |
| ⑤ 말투·반응 특징 | 직접 입력 | 선택 | 짧게 답하고, 지적받으면 이유부터 댄다 |
| ⑥ 대화 난이도 | 선택 | 필수(기본값 있음) | 쉬움 / 보통 / 어려움(저항이 강함) |
| ⑦ 연습 모드 | 선택 | 필수(기본값 있음) | AI가 구성원(내가 직책자) / AI가 직책자(내가 구성원) |
| GROW 모델 적용 | 체크박스 | 선택 | 체크하면 GROW 순서로 진행 |

### 3-3. 동작

- **\[프롬프트 생성\]**: 입력값을 반영한 롤플레이 프롬프트를 결과 영역에 표시합니다.  
  - 연습 모드에 따라 AI가 맡는 역할(구성원 또는 직책자)이 바뀝니다.  
  - GROW를 체크하면 목표(Goal), 현실(Reality), 대안(Options), 실행 의지(Will) 순서와 대화가 끝난 뒤의 피드백 요청 문구가 추가됩니다.  
  - 필수 항목(②, ④)이 비어 있으면 프롬프트를 만들지 않고 "필수 항목을 입력하세요"를 표시합니다.  
- **\[복사\]**: 프롬프트를 클립보드에 복사하고 "복사되었습니다"를 표시합니다.  
- **\[예시 채우기\]**: 샘플 구성원 정보를 모든 항목에 자동으로 입력합니다. 교육 실습 때 바로 써 볼 수 있게 하는 용도입니다.  
- **\[초기화\]**: 모든 입력값과 생성된 프롬프트를 지웁니다.  
- **AI 바로가기 링크**: 누르면 새 탭에서 해당 서비스가 열립니다.

## 5\. 필수 기능과 추가 기능

### 필수 기능 (이번 HTML에서 구현)

1. 사용 방법 안내 3단계 표시  
2. 구성원 정보 입력 (호칭과 항목 ①\~⑦), GROW 적용 여부 선택  
3. \[프롬프트 생성\]: 연습 모드와 GROW 적용 여부에 따라 다른 프롬프트 생성  
4. 필수 항목이 비어 있을 때 안내 메시지 표시  
5. \[복사\]와 완료 안내  
6. \[예시 채우기\]  
7. \[초기화\]  
8. Claude, Gemini 바로가기 링크 (새 탭)

### 추가 기능 (이번 구현에서 제외, 이후 검토)

- 페이지 안에서 AI와 실시간으로 대화하기 (API 키 필요)  
- 구성원별 면담 기록 저장과 이력 조회 (기록 삭제, 내보내기 포함)  
- 구성원 프로필 여러 개를 저장하고 불러오기  
- 대화가 끝난 뒤 코칭 역량 점수를 자동으로 매기기

## 6\. 완료 기준

| 번호 | 행동 | 기대 결과 |
| :---- | :---- | :---- |
| 1 (필수 조건) | HTML 파일 하나를 더블클릭한다 | 다른 파일이나 로그인, 인터넷 연결 없이 크롬에서 열린다 |
| 2 | \[예시 채우기\]를 누른다 | 입력 항목이 모두 채워진다 |
| 3 | 직무·연차나 현재 이슈를 비우고 \[프롬프트 생성\]을 누른다 | 프롬프트 대신 "필수 항목을 입력하세요"가 표시된다 |
| 4 | 'AI가 구성원' 모드로 생성한 뒤, 'AI가 직책자'로 바꿔 다시 생성한다 | 첫 프롬프트에는 "당신은 구성원 역할"이, 두 번째에는 "당신은 직책자 역할"이 들어 있다 |
| 5 | GROW를 체크하고 생성한 뒤, 체크를 풀고 다시 생성한다 | 체크했을 때만 목표·현실·대안·실행 단계와 피드백 요청 문구가 들어 있다 |
| 6 | \[복사\]를 누르고 메모장에 붙여 넣는다 | "복사되었습니다"가 표시되고, 붙여 넣은 내용이 화면의 프롬프트와 같다 |
| 7 | \[초기화\]를 누른다 | 모든 입력값과 생성된 프롬프트가 지워진다 |
| 8 | Claude 또는 Gemini 링크를 누른다 | 새 탭에서 해당 사이트가 열린다 |

## 7\. 한계 및 비목표

1. **페이지 안에서 AI와 대화하지 않는다.** 프롬프트를 만드는 것까지만 하고, 실제 연습은 외부 AI 서비스에서 한다.  
2. **면담 기록과 구성원 정보를 저장하지 않는다.** 새로고침하면 입력값이 사라진다. 인사 정보이므로 호칭은 실명 대신 별칭을 쓰도록 안내한다.  
3. **코칭 모델은 GROW 하나만 제공한다.** AI 응답의 품질은 사용하는 AI 서비스에 따라 달라지며, 페이지가 보장하지 않는다.

## 8\. 검증 방법

- **비교 대상**: \[예시 채우기\]로 입력된 값과, 그 값으로 생성된 프롬프트  
- **절차**  
  1. \[예시 채우기\]를 누르고, 입력된 값을 항목별로 메모장에 목록으로 적는다.  
  2. \[프롬프트 생성\]을 누른다.  
  3. 생성된 프롬프트에서 목록의 각 값을 찾아(Ctrl+F) 하나씩 대조한다. 모든 값이 그대로 들어 있는지 확인한다.  
  4. 연습 모드만 바꿔 다시 생성하고, 두 프롬프트를 비교해 역할 문구만 바뀌었는지 확인한다.

## 부록: 기획 과정 기록

- **진행 방식**: AI(Claude)가 먼저 질문하고, 작성자가 답하는 방식으로 7개 질문을 거쳐 구체화했다.  
- **작성자가 직접 정하거나 수정한 내용**  
  - 처음 아이디어는 'AI가 구성원이나 직책자가 되어 대화하는 코칭 연습 프로그램'이었다. 과제 제약(챗봇·API 제외)에 맞춰 '프롬프트 생성기'로 방향을 바꾸고, 실시간 대화는 추가 기능으로 분류했다.  
  - 코칭 모델은 고정하지 않고, 사용자가 GROW 적용 여부를 고르는 선택 항목으로 정했다.  
  - 구성원 이름과 면담 기록 누적 기능을 필수로 넣으려 했으나, 범위가 커지고 인사 정보 저장 문제가 있어 기록 기능은 추가 기능으로 옮겼다. 이름은 저장하지 않는 선택 입력(호칭)으로만 남겼다.
