# 영화 티어리스트 웹페이지 기획서

## 1. 누가 쓰나
- 강의에서 시연하는 강사가 쓴다.

## 2. 무엇을 하려고
- 영화에 순위(등급)를 매기기 위해 쓴다.

## 3. 화면과 동작
- 등급 칸은 **S · A · B · C · D** 5단계로 둔다.
- 화면 아래에 **"미분류"** 칸을 두고, 아직 등급을 정하지 않은 영화를 모아 둔다.
- 영화는 **마우스로 끌어다 놓아(드래그)** 등급 칸으로 옮긴다.
- 같은 등급 칸 안에서도 드래그로 영화의 **앞뒤 순서를 바꿀 수 있다**.
- 영화 카드에는 **제목 + 개봉연도 + 감독**을 보여 준다.
- 새 영화를 **추가**할 수 있고, 추가한 영화는 미분류 칸에 나타난다.
- 영화를 **삭제**할 수 있다.
- 브라우저를 닫았다 다시 열어도 **배치가 그대로 남는다**.
- **"처음으로 되돌리기"** 버튼을 누르면 처음 상태로 돌아간다.

## 4. 필요한 자료
- 처음 열었을 때 들어 있을 **한국 영화 위주 10편** (AI가 골라 준다).

## 5. 완성 기준
1. 처음 열면 한국 영화 10편이 미분류 칸에 보인다.
2. 영화 하나를 끌어서 S칸에 놓으면 S칸으로 옮겨진다.
3. 새 제목을 입력해 추가하면 미분류 칸에 나타난다.
4. 영화를 삭제하면 화면에서 사라진다.
5. 브라우저를 닫았다 다시 열어도 옮긴 위치가 그대로 남아 있다.
6. "처음으로 되돌리기"를 누르면 처음 10편이 미분류 칸에 있는 상태로 돌아간다.

---

## 아직 정하지 않은 것 (AI가 임의로 넣지 않음)
- 영화를 **어떤 방법으로 삭제**할지 (카드의 × 버튼, 휴지통 칸으로 드래그 등)
- 새 영화를 추가할 때 **연도·감독도 꼭 입력해야 하는지**, 제목만으로도 추가되는지
- 삭제나 되돌리기 전에 **"정말 하시겠습니까?" 확인 창**을 띄울지
- 등급 칸의 **색깔**과 페이지 **제목** 문구
- 등급 칸에 있던 영화를 다시 **미분류 칸으로 되돌릴 수 있는지**
