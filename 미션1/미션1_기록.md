# 미션 1 기록

- AI A 이름 / 주요 대화 캡처 파일명: Claude (claude-opus-5-5) / A\_질문1.png, A\_질문2.png, A\_질문3.png, A\_결과.png  
- AI B 이름 / 주요 대화 캡처 파일명: Gemini (3.8 사고 모델) / B\_요청.png, B\_답변.png  
- AI가 물어서 내가 정한 것:  
  - 쓰는 사람: 강의 시연용  
  - 목적: 영화 순위 매기기  
  - 등급: S·A·B·C·D 5단계  
  - 처음 자료: 유명 영화 10편을 미리 넣음 (한국 영화 위주로 AI가 고름)  
  - 옮기는 방법: 마우스 드래그  
  - 같은 칸 안에서도 드래그로 순서 변경  
  - 다시 열어도 배치가 남고, "처음으로 되돌리기" 버튼도 둠  
  - 영화 추가·삭제 모두 가능  
  - 등급 안 정한 영화는 화면 아래 "미분류" 칸에 모음  
  - 카드에는 제목 \+ 연도 \+ 감독 표시  
  - 완성 기준 6개는 AI가 제안한 문장을 그대로 채택  
- 같은 행동으로 비교한 결과(해본 행동 → 기대 결과 → A의 결과 / B의 결과):

| 해본 행동 | 기대 결과 | A의 결과 | B의 결과 |
| :---- | :---- | :---- | :---- |
| 파일을 처음 연다 | 한국 영화 10편이 미분류 칸에 보인다 | O | O |
| 기생충을 끌어 S칸에 놓는다 | S칸으로 옮겨진다 | O | O |
| S칸 안에서 두 영화 순서를 바꾼다 | 순서가 바뀐다 | O | O |
| 새 제목을 입력해 추가한다 | 미분류 칸에 나타난다 | O | O |
| 영화 하나를 삭제한다 | 화면에서 사라진다 | O (× 누르면 바로 삭제) | O (확인 창이 뜬 뒤 삭제) |
| 브라우저를 닫고 파일을 다시 연다 | 옮긴 위치가 그대로 남는다 | O | O |
| "처음으로 되돌리기"를 누른다 | 10편이 미분류 칸에 있는 처음 상태로 돌아간다 | O | O |

- 선택한 파일명과 고른 이유: 영화\_A\_초안.html — 두 파일 모두 완성 기준을 전부 통과했지만, A가 등급 색깔과 카드 모양 등 화면이 더 보기 좋아 강의 시연용으로 더 적합하다고 판단했다.
