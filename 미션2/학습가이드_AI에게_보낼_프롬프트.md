# 미션 2 학습 가이드

## 핵심 한 줄

버그는 “되는 것과 안 되는 것의 차이”를 찾으면 원인이 보인다. 여기선 그 차이가 **제목의 띄어쓰기**였다.

## 쉬운 비유

영화 카드마다 이름표(id)를 붙이는데, 이름표에 테이프(따옴표)를 안 붙이고 꽂았다. ‘토이 스토리’라고 쓰면 띄어쓰기에서 종이가 끊어져 ‘토이’만 남는다. 나중에 “토이 주인 누구야?” 하고 찾으면 그런 영화가 없어 아무 일도 안 일어난다.

## 문제 코드 → 고친 코드

```js
// 전: 글자를 이어 붙여 HTML을 만듦 (data-id 값에 따옴표 없음)
'<button ... data-id=' + item.id + '>' + item.title + '</button>'
// → <button data-id=토이 스토리>  → 브라우저는 data-id="토이", 스토리="" 로 읽음

// 후: 버튼을 직접 만들고 값을 따로 넣음 (띄어쓰기·특수문자 안전)
element.dataset.id = item.id;
element.textContent = item.title;
```

## 직접 확인하는 법 (캡처 추천 포인트)

1. 영화\_수정전.html 열기 → ‘처음으로’ → 8개를 하나씩 S로 옮기기 → 3개 실패 확인  
2. ‘토이 스토리’ 카드 오른쪽 클릭 → 검사(F12) → `data-id="토이" 스토리=""` 확인  
3. ‘토이’ 추가 → ‘토이 스토리’ 누르고 S → ‘토이’가 옮겨지는 것 확인  
4. 영화\_수정1.html 열기 → **먼저 ‘처음으로’** → 같은 테스트 반복 → 모두 성공

## 4단계: AI에게 보낼 원인 질문 (기획서.md, 영화\_수정전.html 첨부 후 붙여넣기)

```
기획서와 HTML을 줄게. 직접 써 보니 기획서와 다르게 동작하는 곳이 있어.
- 어떻게 했는지: ‘처음으로’를 누른 뒤 영화 8개를 하나씩 카드를 누르고 S 글자를 눌러 옮겼고, 끌어서 A 칸에 놓기도 해 봤어.
- 원래 어떻게 되어야 하는지: 8개 모두 누르거나 끌어서 S·A·B·C로 옮겨져야 해.
- 실제로 어떻게 됐는지: 센과 치히로의 행방불명, 어벤져스: 엔드게임, 토이 스토리는 누르기·끌기 둘 다 미분류에 그대로 남아. 눌러도 선택 테두리가 안 생겨.
- 되는 경우와 안 되는 경우의 차이: 안 되는 3개는 제목에 띄어쓰기가 있어. 내가 추가한 ‘해리 포터’도 안 되고, ‘토이’는 잘 돼.
왜 이런 문제가 생기는지 쉬운 말로 설명하고, 그 설명이 맞는지 내가 브라우저에서 확인할 방법을 알려 줘.
아직 고치지는 마.
```
