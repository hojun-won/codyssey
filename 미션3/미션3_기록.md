# 미션 3 기록

## 1단계: 받은\_피드백.md를 열기 전에 직접 써 본 결과

`민수_기획서.md`의 완성 기준을 한 줄씩 직접 해 봤습니다. (크롬, 노트북 화면 1280×800 기준)

| 완성 기준 | 한 행동 | 실제 결과 | 판정 |
| :---- | :---- | :---- | :---- |
| 영화가 한 칸에만 있고, 옮긴 칸에 남는다 | 영화 8개를 하나씩 눌러 S·A·B·C로 나눠 옮김. ‘라라랜드’를 고르고 ‘선택한 영화 되돌리기’를 누름 | 8개 모두 누른 칸으로 옮겨지고 한 칸에만 있음. 띄어쓰기 있는 제목(토이 스토리 등)도 잘 옮겨짐. 되돌리기도 됨 | 통과 |
| 제목을 입력하면 새 영화 카드가 생긴다 | ‘해리 포터’를 입력하고 ‘추가’ | 미분류에 카드가 생기고 S로도 옮겨짐 | 통과 |
| 같은 브라우저에서 다시 열어도 영화와 등급이 남는다 | 영화를 S·A로 옮기고 ‘해리 포터’를 추가한 뒤 새로고침(F5) | 추가한 ‘해리 포터’가 사라지고 8개 모두 미분류로 돌아옴 | **미충족** |
| 화면 폭이 좁아져도 오른쪽이 잘리지 않는다 | 창 폭을 375px(휴대폰 크기)로 줄임 | 제목이 ‘민수의 영화 티어리스’에서 잘리고 ‘추가’·‘처음으로’ 버튼이 안 보임. 옆으로 스크롤도 안 됨 | **미충족** |
| ‘처음으로’를 누르면 처음 8개가 모두 미분류로 | ‘해리 포터’를 추가해 S로, ‘기생충’을 A로 옮긴 뒤 ‘처음으로’ | 처음 8개만 미분류에 남고 ‘해리 포터’는 사라짐 | 통과 |
| 외부 파일이나 로그인 없이 HTML 한 장으로 열린다 | 파일만 더블 클릭해 열기 | 바로 열림. 외부 파일 연결 없음 | 통과 |

쓰다가 눈에 띈 것: 제목을 비우고 ‘추가’를 누르니 글자 없는 카드가 생기고, 안내 문구가 “‘’를 추가했어요.”로 나오고, 위 숫자가 ‘11편 중’처럼 늘어남.

## 2·3단계: 받은 의견 확인과 판단

| 받은 의견 | 직접 해 본 결과 | 반영 / 보류 / 되묻기 | 이유 (되묻기라면 물을 질문) |
| :---- | :---- | :---- | :---- |

| (AI) 세 가지 외에는 완성 기준을 잘 지킴 | 창 폭 375px에서 오른쪽이 잘리고 버튼이 안 보이며 옆으로 스크롤도 안 됨 → **틀림 (놓침)** | 반영 | 기획서의 ‘화면 폭이 좁아져도 오른쪽이 잘리지 않는다’를 지키지 못함 |

| (동료) ‘8편 중 3편 나눔’ 표시가 좋음 | 영화를 옮길 때마다 숫자가 바뀜 → 맞음 | 반영 (잘된 점으로 유지) | 직접 확인한 장점 |

| (동료) 휴대폰으로 열어 보니 좀 불편했어요 | 무엇이 불편했는지 적혀 있지 않음. 375px로 줄여 보니 버튼이 잘리는 문제는 있었음 | 되묻기 | “휴대폰에서 어떤 행동을 할 때 무엇이 불편했나요? 혹시 오른쪽 버튼(추가·처음으로)이 안 보였나요?” |

- 아무도 말하지 않았는데 내가 찾은 것:  
  1. **‘처음으로’는 잘 작동함.** AI는 추가한 영화가 남는다고 했지만, 실제로는 깨끗하게 처음 8개로 돌아감.  
  2. 빈 제목을 추가하면 안내 문구가 “‘’를 추가했어요.”로 나오고, 위 숫자도 빈 카드까지 세어 늘어남.
